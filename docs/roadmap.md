# DevRecipe roadmap

> **Documentation type:** explanation. This page defines admission criteria for future expansion ideas. For shipped behaviour, see the [project overview](../README.md), [preflight and review reference](preflight-and-review.md), [status and narrow removal reference](status-and-removal.md), and [acceptance checks](../tests/acceptance/README.md).

## Admission criteria

Any future expansion requires an explicit scope decision, a separate safety contract, provider-specific acceptance coverage, and documentation updates.

## Candidate expansions

- Read the selected manifest to discover package updates, then interactively validate proposed updates.
- Read the selected manifest to discover packages to uninstall, then interactively validate proposed uninstalls.
